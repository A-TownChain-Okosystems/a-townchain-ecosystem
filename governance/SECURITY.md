# Security Findings Register

Security findings are tracked here only when they are findings of the ecosystem
governance layer. Component-specific findings remain in the canonical component
security records.

Each finding requires: ID, severity, status, evidence reference. Status values:
`OPEN`, `TRIAGED`, `FIXED`, `WONTFIX`.

No ecosystem-governance security finding is asserted by this initial framework.
