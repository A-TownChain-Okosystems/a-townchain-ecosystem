# Canonical Organization Components

The `components/` tree contains the five canonical system imports maintained by
this umbrella repository via full-history Git subtrees.

The source repositories remain the authoritative SSOTs for their domains.
Changes to component implementation belong in the source repository and are
then synchronized here with the `Ecosystem Subtree Sync` workflow.

Canonical imports are documented in `MIGRATION_MANIFEST.yaml` and
`docs/decisions/ADR-0001-system-of-systems-umbrella.md`.
